# EA SPORTS FC 27 — Infinite SP

**Created by Leiva**

A simple Infinite SP patch for Career Mode on PS5.

- **Title ID:** PPSA34015
- **Patch format:** PS-Game-Patch XML
- **Loader:** CheatRunner
- **Author:** Leiva

### Installation

1. Download `PPSA34015.xml`.
2. Place it in the appropriate CheatRunner XML patches directory.
   /data/cheatrunner/patches/xml_prospero/
4. Refresh the patches list and apply **SP INF - Career Mode**.

Tested on the author's setup. Compatibility with other game versions and configurations is not guaranteed.

What the patch does is lock your SP amount so it doesn't decrease;
Reset all your SP so you can reallocate them, then activate it to avoid spending them.
